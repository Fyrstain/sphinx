## NPM package and definitions

The following file contains all the value sets, profiles, extensions, page list, and URLs defined in this implementation guide:

- [NPM package](package.tgz)

In addition, definition files are available in the following formats:

- [XML](definitions.xml.zip)
- [JSON](definitions.json.zip)
- [TTL](definitions.ttl.zip)

These files should be the first choice when generating any implementation artifact because they contain all the rules that make these profiles valid. However, implementers will still need to become familiar with the specification and the applicable profiles to achieve a conformant implementation. See the overview of [FHIR profile and resource validation]({{ site.data.fhir.path }}validation.html).
