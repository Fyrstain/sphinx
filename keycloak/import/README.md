# Keycloak Import

This directory contains import files for Keycloak. These files are used to configure Keycloak with the necessary users, roles, and clients for our application.

## Usage

To use these import files, follow these steps:

1. Start your Keycloak server.
2. In the Keycloak admin interface, go to 'Realm Settings'.
3. Click on 'Import'.
4. Select the desired import file from this directory.
5. Click on 'Save'.

This will configure Keycloak according to the settings defined in the import file.
